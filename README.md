# RNA-Seq Technology Detective

`seq-detective` is a tool for determining the chemistry that generated a FASTQ RNA-seq dataset 
without prior knowledge of the source.  This is useful when scraping public sequencing archives,
where metadata availability is inconsistent.

# Installation
## prerequisites
 - [meson](https://mesonbuild.com/Getting-meson.html)
  - check your distro's package manager, `sudo apt install meson`
 	- or from pip: `pip3 install --user meson`
 - OpenMP
```
git clone https://github.com/czbiohub-sf/seq-tech-detective --depth=1
cd seq-tech-detective
meson setup build
meson compile -C build
```

# How It Works

## Phase 1: FASTQ metrics
We sample the first n (=2000000) reads to collect:

 - read lengths
 - barcode onlist hit rate
   - 10x v2
   - unimplemented:
     - 10x v1, v3, inDrops v1, v2, v3
 - linker sequence hit rate (unimplemented)
   - inDrops v1, v2, sciRNAseq-3, Microwell-seq
 - poly-T/poly-A tail find rate

## Phase 2: Aligner (when reference genome provided)
We align (hisat2) the first n (=5000) reads to determine

 - expression sparsity
 - (if paired reads)
   - mixed mapping rate

ambiguous runs may be aligned with a larger read subset (n=1000000).

## Phase 3: Public Metadata (when sequence accession provided)
We perform two further checks when accessions are available.

 - experiment-level library size variation
 - hierarchical metadata text search

## Final stage: classification
The previous raw fingerprinting results are written to a table, which is then
read by the judge (rule-based | cluster-based) to call, for each input row:

 - bulk/single cell
   - broad technology class (barcoded/droplet/plate) (needs definition)
     - specific chemistry (10x, SmartSeq2, inDrops, ...)

specific call columns will be named so as to be compatible with unified processing
tools such as `universc`
